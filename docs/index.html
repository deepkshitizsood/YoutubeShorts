Factodixs Shorts Agent

This is a personal, single-operator automation tool that generates and publishes daily YouTube Shorts to the @Factodixs YouTube channel, and reads that channel's own analytics to inform future content decisions.

It is not a public product, is not distributed to other users, and does not access any Google account's data other than the operator's own channel.
