Privacy Policy

Effective: August 2026 · Applies to: Factodixs Shorts Agent

Factodixs Shorts Agent is a personal automation tool built and operated by a single individual to manage one YouTube channel, @Factodixs. It is not offered to the public and does not process data belonging to anyone other than its operator.

What data this application accesses

Using Google OAuth, this application accesses only the operator's own YouTube channel, via the YouTube Data API and YouTube Analytics API, specifically to:

  • Upload new videos to the operator's own channel
  • Read metadata (titles, IDs, publish dates) of videos the operator has uploaded
  • Read aggregate performance analytics (views, likes, comments, watch time) for the operator's own channel and videos

What this application does not do

This application does not access Gmail, Google Drive, Contacts, or any other Google service. It does not access any other user's YouTube channel, videos, or data. It does not access individual viewer/subscriber identities - only aggregate, channel-level analytics.

How data is used

Data obtained via the APIs above is used solely to automate publishing a daily video to the operator's own channel and to inform which topics and formats to produce next, based on the channel's own historical performance. This data is stored in a private, version-controlled repository controlled by the operator and is never sold, shared, or disclosed to any third party.

Data retention

Performance snapshots and content history are retained indefinitely in the operator's private repository for the sole purpose of improving future content, and may be deleted by the operator at any time.

Revoking access

The operator (or anyone whose account is connected) can revoke this application's access at any time via Google Account permissions.
